Handicap calculator

Track 18-hole rounds with course rating and slope from the tee box you played. Your Handicap Index follows the World Handicap System (lowest differentials from your record, last 20 scores when you have more than 20). Data stays in this browser unless you export it.

Handicap Index

—

Enter each round’s adjusted gross (after maximum hole score / net double bogey) with the course rating, slope, and par for the tees you played. PCC defaults to 0. Your index uses the lowest differentials from your record (per WHS: last 20 scores when you have more than 20).

This tool does not apply national union adjustments, exceptional score reduction, or soft/hard caps—your official index may differ slightly.

Course lookup

Search courses and load course rating, slope, and par from the GolfCourseAPI catalog (free tier available). Paste your API key below; it is stored only in this browser. Course search must be opened over HTTP from this project’s dev server (default http://127.0.0.1:8765/app.html after npm start or node server.mjs) so requests use the built-in same-origin API proxy on localhost / 127.0.0.1 / ::1. Opening the HTML as a file or using plain python -m http.server usually shows “Failed to fetch” in the browser.
